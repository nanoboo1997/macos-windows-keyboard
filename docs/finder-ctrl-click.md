# Ctrl+คลิกเลือกไฟล์ใน Finder

กฎนี้ให้ Ctrl จากคีย์บอร์ดภายนอกทำงานร่วมกับคลิกซ้ายเป็น Command+คลิก เฉพาะเมื่อ Finder เป็นแอปด้านหน้า คลิกไฟล์ที่ยังไม่เลือกเพื่อเพิ่ม คลิกไฟล์ที่เลือกแล้วเพื่อยกเลิก

## อุปกรณ์และการเปิดใช้

- คีย์บอร์ดภายนอกทุกตัวที่ Karabiner เปิดรับเหตุการณ์อยู่แล้ว รองรับ Ctrl ซ้ายและขวา
- เมาส์ภายนอกที่ Karabiner รับเหตุการณ์ได้ ไม่จำกัดยี่ห้อหรือรุ่น ทั้ง USB ตัวรับไร้สาย และ Bluetooth
- ใน Karabiner → Devices เปิด Modify events ของรายการเมาส์ การเปิดเฉพาะรายการคีย์บอร์ดไม่พอ
- หากต้องการใช้กับเมาส์ที่ต่อใหม่อัตโนมัติ เปิด **Expert → Modify events for pointing devices by default** (Karabiner 16.2 ขึ้นไป) ค่านี้ตรงกับ `ignore_pointing_device_events_by_default: false` ในโปรไฟล์ที่เลือก
- การตั้งค่า Modify events รายอุปกรณ์ที่เคยปิดไว้มีผลเหนือค่าเริ่มต้น ต้องเปิดรายการนั้นเอง
- ตัวติดตั้งเพิ่มกฎ แต่ไม่เปลี่ยนค่ารายอุปกรณ์หรือค่าเริ่มต้นดังกล่าว
- คง Modify events ของคีย์บอร์ดในตัวไว้เป็นปิด ไม่เปิดรับแทร็คแพด Apple

Magic Mouse และแทร็คแพด Apple ไม่รองรับการแปลงคลิกด้วยวิธีนี้ การเปิดค่าเริ่มต้นไม่ได้บังคับเปิดอุปกรณ์ Apple ที่ Karabiner ข้ามไว้ กฎคลิกใช้เงื่อนไข `is_pointing_device: true` กับอุปกรณ์ที่เปิดรับแล้ว; Karabiner 16.3.0 ไม่มีเงื่อนไข `is_built_in_pointing_device` สำหรับกฎนี้

อ้างอิง: [ค่าเริ่มต้นใน profile.hpp](https://github.com/pqrs-org/Karabiner-Elements/blob/v16.3.0/src/share/core_configuration/details/profile.hpp), [การข้ามอุปกรณ์ Apple](https://github.com/pqrs-org/Karabiner-Elements/blob/v16.3.0/src/share/device_utility.hpp), [เงื่อนไขอุปกรณ์](https://github.com/pqrs-org/Karabiner-Elements/blob/v16.3.0/src/share/manipulator/conditions/device.hpp)

## พฤติกรรมและข้อจำกัด

- Ctrl+คลิกใน Finder จะไม่เปิดเมนูคลิกขวา คลิกขวาปกติยังใช้ได้
- กฎนี้ไม่เปลี่ยน Ctrl+คลิกในแอปอื่น รวมถึงช่องเลือกไฟล์ที่เปิดโดยแอปอื่น
- Ctrl+Shift+คลิกและชุดปุ่มที่มีตัวปรับแต่งเพิ่มเติมนอกเหนือจาก Caps Lock ไม่ถูกแปลง
- Ctrl+ลากจะมีพฤติกรรมเหมือน Command+ลากขณะกดปุ่มเมาส์ค้าง
- ควรปล่อย Ctrl และปุ่มเมาส์ก่อนปิดกฎหรือสลับโปรไฟล์
- การกด Ctrl ข้างเดียวกันพร้อมกันจากคีย์บอร์ดภายนอกหลายตัวไม่ได้ออกแบบไว้เป็นกรณีใช้งานหลักและยังไม่ได้ทดสอบ
- การเปิดค่าเริ่มต้นให้เมาส์ทำให้ Karabiner รับเหตุการณ์จากอุปกรณ์ชี้ตำแหน่งที่รองรับเพิ่มขึ้น กฎอื่นที่ผู้ใช้มีและครอบคลุมเมาส์อาจเริ่มทำงานด้วย

## อัปเดตจากกฎ Logitech

ตัวติดตั้งไม่เขียนทับกฎเดิม กฎรุ่นนี้ใช้ชื่อ **External keyboards: Ctrl-click selects multiple files in Finder with external mice** ต่างจากรุ่นเดิมที่ลงท้าย **with Logitech mouse**

1. สำรองการตั้งค่าและบันทึกความเป็นเจ้าของของตัวติดตั้งก่อน
2. หากกฎเก่าติดตั้งผ่านสคริปต์และไม่ได้แก้เอง ใช้ `bash uninstall.sh` แล้ว `bash install.sh` เพื่อถอนกฎที่สคริปต์เป็นเจ้าของและติดตั้งชุดใหม่ กฎอื่นจะยังอยู่
3. หากเพิ่มกฎเก่าด้วยมือ ให้ปิดกฎ **with Logitech mouse** ใน Complex Modifications แล้วติดตั้งกฎรุ่นใหม่ สคริปต์ไม่ลบกฎที่เพิ่มด้วยมือ
4. หากรัน install ทับชุดเดิมโดยตรง ตัวติดตั้งจะเพิ่มกฎเมาส์ทั่วไปหนึ่งชุดและรักษากฎ Logitech เดิมไว้ แนะนำปิดกฎ Logitech เพื่อให้เหลือกฎ Finder ที่ใช้งานชุดเดียว กฎแรกที่ตรงจะรับคลิก จึงไม่ได้ส่งคลิกซ้ำจากทั้งสองชุด
5. เปิดรับเมาส์ตามหัวข้ออุปกรณ์ด้านบน

## ผลทดสอบ

ผู้ใช้ทดสอบกฎรุ่น Logitech ใน Finder กับคีย์บอร์ดภายนอกและเมาส์ Logitech แล้ว: คลิก A → Ctrl ค้างคลิก C ได้ A+C → ยังกด Ctrl คลิก A ซ้ำ เหลือ C ตัวเดียว

รุ่นเมาส์ทั่วไปตรวจเงื่อนไขด้วยอุปกรณ์จำลองหลายรุ่นแล้ว ยังไม่ได้ทดสอบกดจริงกับเมาส์ยี่ห้ออื่น ไม่ได้แยกทดสอบ Ctrl ทั้งสองข้าง คีย์บอร์ดภายนอกทุกตัว การเชื่อมต่อใหม่ หรือหลังรีสตาร์ต

## เหตุผลของการติดตาม Ctrl

เหตุการณ์คลิกมาจากเมาส์ จึงใช้เงื่อนไขอุปกรณ์ของคลิกเพียงอย่างเดียวแยก Ctrl จากคีย์บอร์ดในตัวไม่ได้ กฎจึงจดสถานะ Ctrl ซ้าย/ขวาจากคีย์บอร์ดภายนอก โดยส่ง Ctrl เดิมผ่านตามปกติ แล้วคืนสถานะใน `to_after_key_up`

อย่าใส่ `key_up_value` ใน `set_variable` ที่อยู่ก่อนรายการส่ง Ctrl ใน `to`: Karabiner 16.3.0 ส่งเหตุการณ์ key-up ให้รายการที่ไม่ใช่รายการสุดท้ายทันที ทำให้สถานะถูกล้างก่อนคลิก ปัญหานี้ผ่านการตรวจรูปแบบได้ แต่ทดสอบกดจริงไม่ผ่าน จึงมีการตรวจวงจรสถานะเพิ่มเติม

อ้างอิงพฤติกรรม: [Karabiner 16.3.0 event_sender.hpp](https://github.com/pqrs-org/Karabiner-Elements/blob/v16.3.0/src/share/manipulator/manipulators/basic/event_sender.hpp)

## ย้อนกลับ

1. ปล่อย Ctrl และปุ่มเมาส์
2. ใน Complex Modifications ปิดหรือลบ **External keyboards: Ctrl-click selects multiple files in Finder with external mice**
3. หากต้องการกลับไปใช้เฉพาะ Logitech ให้เปิดกฎเดิมจากไฟล์สำรอง
4. หากเพิ่งเปิดค่าเริ่มต้นเพื่อกฎนี้ ให้ปิด **Expert → Modify events for pointing devices by default** กลับเป็นค่าเดิม
5. คืนค่า Modify events รายเมาส์ที่เปลี่ยนไว้ตามบันทึกเดิม อย่าเปลี่ยนรายการคีย์บอร์ด

หากติดตั้งผ่านสคริปต์ `bash uninstall.sh` จะถอนกฎที่สคริปต์เป็นเจ้าของทั้งหมดตามบันทึก ไม่เปลี่ยนค่าอุปกรณ์หรือค่าเริ่มต้นให้ การคืนไฟล์สำรองทั้งไฟล์จะคืนค่าอื่นด้วย จึงควรใช้เมื่อยังไม่มีการแก้เพิ่มเติมหลังสำรอง ดูรายละเอียดใน [README](../README.md)
