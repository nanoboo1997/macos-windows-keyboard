# คีย์บอร์ด USB และ Bluetooth

กฎชุดนี้เลือกคีย์บอร์ดภายนอกด้วยเงื่อนไข `is_keyboard: true` และ `is_built_in_keyboard: false` ไม่ผูกยี่ห้อ รหัสอุปกรณ์ หรือช่อง Bluetooth ของเครื่องต้นทาง

## ก่อนเปิดใช้

1. จับคู่ Bluetooth หรือเชื่อม USB ให้คีย์บอร์ดพิมพ์ได้ตามปกติก่อน
2. ติดตั้ง Karabiner-Elements จากเว็บไซต์ทางการ และอนุญาตบริการเบื้องหลัง สิทธิ์ Accessibility/Input Monitoring และส่วนขยายไดรเวอร์ตามที่เวอร์ชันนั้นร้องขอ ชื่อรายการอาจต่างกัน ผู้ใช้ต้องยืนยัน Touch ID/รหัสผ่านเอง
3. ติดตั้งกฎตาม [README](../README.md) โดยสำรองการตั้งค่าก่อน
4. เปิด Karabiner → **Devices** เปิด **Modify events** ของคีย์บอร์ดภายนอกที่ต้องการ และปิดของคีย์บอร์ด MacBook ในตัว เมาส์/แทร็คแพดทั่วไปไม่ต้องเปิด
5. ตรวจด้วย EventViewer ว่าปุ่มใต้ Esc ส่ง `grave_accent_and_tilde` หากเป็นรหัสอื่น กฎ Backtick นี้จะไม่ตรง ต้องพิจารณากฎสำหรับผังนั้นแยกต่างหาก

ไม่จำเป็นต้องปิด SIP หรือแก้ไฟล์ระบบ สคริปต์ของ repo ไม่อนุญาตสิทธิ์ ไม่ตั้งอุปกรณ์ และไม่ติดตั้ง Karabiner ให้เอง

## ต่อคีย์บอร์ดตัวใหม่

คีย์บอร์ดมาตรฐานที่ Karabiner รับเหตุการณ์อยู่แล้วจะใช้กฎได้อัตโนมัติ ไม่ต้องเพิ่มรหัสรุ่นลงไฟล์กฎ ถ้าต่อแล้วกฎไม่ทำงาน ให้ตรวจ Devices และ Modify events ก่อน

บางรุ่นรายงานตัวเป็นทั้งคีย์บอร์ดและอุปกรณ์ชี้ตำแหน่ง แม้เป็นคีย์บอร์ดจริง Karabiner อาจปิด Modify events ไว้โดยค่าเริ่มต้น จึงต้องเปิดให้ครั้งแรก นี่เป็นข้อจำกัดของการรับอุปกรณ์ ไม่ใช่การจำกัดกฎไว้เฉพาะคีย์บอร์ดเดิม

หากแสดงรายการอุปกรณ์หลายตัวหรือหลายอินเทอร์เฟซ ให้ใช้ EventViewer ระบุรายการที่รับปุ่มจากตัวที่กดจริง อย่าเปิดทุกรายการโดยไม่ตรวจ

## ตัวอย่าง MCHOSE K99 V3 ผ่าน Bluetooth

ในการตั้งค่าครั้งนี้ คีย์บอร์ดที่แสดงชื่อ **MCHOSE K99 V3-1** รายงานเป็นอุปกรณ์ผสมคีย์บอร์ดและอุปกรณ์ชี้ตำแหน่ง จึงเปิด Modify events เฉพาะรายการนั้นเพื่อให้รับกฎชุดเดิมได้ โดยไม่ได้แก้กฎภาษา กฎ Ctrl หรือการตั้งค่าคีย์บอร์ดในตัว

ตัวอย่างนี้ยืนยันเพียงว่าตรวจพบอุปกรณ์และเปิดรับเหตุการณ์แล้ว **ยังไม่ได้ทดสอบการกดจริงบนคีย์บอร์ด Bluetooth ตัวนี้** ชื่ออุปกรณ์อาจต่างกันตามช่องที่จับคู่ ไม่ควรถือว่าคีย์บอร์ดรุ่นเดียวกันทุกตัวต้องมีชื่อเหมือนกัน

ไม่ได้เปลี่ยนเฟิร์มแวร์หรือหน่วยความจำในคีย์บอร์ด กฎยังทำงานบน Mac ผ่าน Karabiner เท่านั้น จึงไม่ติดตามไปเมื่อจับคู่กับคอมพิวเตอร์อีกเครื่อง

## ย้อนกลับเฉพาะอุปกรณ์

ปิด Modify events ของคีย์บอร์ดนั้นใน Devices เพื่อหยุดให้ Karabiner แปลงปุ่มของอุปกรณ์นั้น หรือปิดกฎที่ต้องการใน Complex Modifications ถ้าต้องคืนค่าทั้งไฟล์ ให้สำรองค่าปัจจุบันก่อน แล้วคืนจากสำรองที่เลือกอย่างระมัดระวัง เพราะการคืนทั้งไฟล์ย้อนการเปลี่ยนแปลงอื่นหลังจุดสำรองด้วย
