# สถานะการตรวจสอบ

เอกสารนี้แยกผลที่ตรวจแล้วออกจากสิ่งที่ยังไม่ได้ทดสอบจริง ไม่ใช่การรับรองทุกคีย์บอร์ดหรือทุกแอป

## ตรวจแล้ว

- ไฟล์กฎผ่านตัวตรวจรูปแบบของ Karabiner-Elements 16.3.0
- กฎทั่วไปทั้งห้าชุดใน repo มีเนื้อหาตรงกับกฎที่เปิดใช้งานบนเครื่องต้นทาง โดยไม่เผยแพร่โปรไฟล์ทั้งเครื่องหรือรหัสอุปกรณ์
- ในการตั้งค่าเครื่องต้นทาง Karabiner โหลดไฟล์ที่อัปเดตแล้ว และจำกัดกฎเฉพาะคีย์บอร์ดภายนอก
- ผู้ใช้ทดสอบการสลับไทย–อังกฤษใน Notes บนคีย์บอร์ด USB แล้ว ระหว่างการทดสอบมีจังหวะที่ยังไม่ได้ตัวอักษรตามคาด ก่อนแจ้งว่าสลับได้แล้ว
- ผู้ใช้ยืนยันว่า Shift+Backtick และคีย์บอร์ด MacBook ในตัวใช้งานได้หลังตั้งค่า การทดสอบนี้ไม่ได้ยืนยันทุกผังภาษา
- ตรวจพบ MCHOSE K99 V3 ผ่าน Bluetooth และเปิด Modify events โดยยืนยันว่ากฎเดิมและรายการอุปกรณ์อื่นไม่เปลี่ยน

## การทดสอบอัตโนมัติ

รันด้วย Python 3 บน macOS โดยใช้ไฟล์ตั้งค่าจำลองเท่านั้น:

```sh
python3 -m unittest discover -s tests -v
```

ชุดทดสอบครอบคลุมการสำรอง การติดตั้งซ้ำ การถอนแบบคงกฎเดิมและกฎที่เพิ่มภายหลัง โปรไฟล์หลายชุด กฎที่แก้ภายหลัง JSON เสีย symlink การทำงานพร้อมกัน การกู้หลังการเขียนถูกขัดจังหวะ และการเพิ่มกฎ Terminal ให้การติดตั้งรุ่นก่อนโดยไม่เขียนทับสี่ชุดเดิม

มีการตรวจเงื่อนไขของไฟล์กฎสำหรับคีย์บอร์ดภายนอก/ในตัวและแอป Terminal ด้วย การตรวจนี้เป็นการตรวจข้อมูลกฎ ไม่ใช่การส่งปุ่มจริงผ่าน Bluetooth หรือการทดสอบหน้าแอป

Python ใช้เฉพาะการทดสอบ ตัวติดตั้งใช้เครื่องมือที่มากับ macOS

ผลรันล่าสุด: **ผ่าน 25 กรณี** บน macOS เมื่อ 2 พฤศจิกายน 2026 โดยใช้ไฟล์จำลอง ไม่ใช่การทดสอบกดจริง

## ยังไม่ได้ทดสอบจริงครบ

- Ctrl+C/V/X/Z/A/S/F/Y บนคีย์บอร์ดจริงในทุกแอป
- Ctrl+C/V ใน Apple Terminal และ iTerm2 หลังเพิ่มกฎเสริม
- ปุ่มจริงบน MCHOSE K99 V3 ผ่าน Bluetooth หลังเปิดใช้
- การสลับภาษาใน Safari และช่องพิมพ์ทั่วไปครบตามแผน
- การเชื่อมต่อใหม่ การปลุกจากพักเครื่อง และหลังรีสตาร์ต
- การติดตั้งบน Mac เครื่องอื่น

ผู้ใช้เลือกข้ามการทดสอบบางส่วน จึงไม่รายงานว่าส่วนเหล่านี้ผ่านแล้ว

## วิธีลองเอง

1. ใช้เอกสารว่างใน Notes หรือ TextEdit เริ่มด้วย ABC
2. กด A → Backtick → รอไทย → A → Backtick → รอ ABC → A ควรได้ `aฟa` เมื่อใช้ผัง Thai ที่ตรงกับการทดสอบ
3. ใน ABC กด Shift+Backtick ควรได้ `~` และตรวจว่าคีย์บอร์ดในตัวยังพิมพ์ Backtick ตามเดิม
4. ใช้ข้อความทดลองกับ Ctrl+A/C/V/Z/X, Ctrl+S/F และ Ctrl+Y โดยดูปุ่มลัดที่แอปรองรับ
5. ใน Terminal เลือกข้อความทดลองแล้วกด Ctrl+C จากนั้นวางในเอกสารว่างด้วย Ctrl+V เพื่อไม่เผลอรันข้อความที่วาง
6. เมื่อเปิดกฎเสริม Ctrl+C ใน Terminal จะไม่หยุดคำสั่ง แม้ไม่มีข้อความเลือกอยู่ ปิดเฉพาะกฎเสริมเพื่อคืนพฤติกรรมเดิม แล้วจึงทดสอบการหยุดคำสั่งที่ไม่มีผลข้างเคียง
