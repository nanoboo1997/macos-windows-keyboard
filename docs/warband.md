# กฎคีย์บอร์ด Mount & Blade: Warband

กฎเสริมนี้ใช้เฉพาะคีย์บอร์ดภายนอกที่ Karabiner รับเหตุการณ์ และเฉพาะเกมที่รายงาน bundle ID `taleworlds.Mount-and-Blade`:

- Ctrl+X ส่ง Ctrl+X ให้เกม แทนการเปลี่ยนเป็น Command+X ใช้สูตรในหน้ากระเป๋าเมื่อเปิด Enable Cheats ในเกมแล้ว
- ปุ่มใต้ Esc ส่ง Control+Space เพื่อเปลี่ยนภาษา แล้วส่งปุ่มเดิมให้เกมเพื่อซูม ทุกครั้งที่กดมีทั้งสองผล หากเกมใช้ปุ่มซูมอื่นหรือตั้งปุ่มลัดเปลี่ยนภาษาอื่น อาจต้องปรับค่า
- Shift+ปุ่มใต้ Esc และปุ่มอื่นยังใช้กฎเดิม กฎนี้ไม่ครอบคลุมคีย์บอร์ดในตัว

ผู้ใช้ยืนยันเมื่อ 12 พฤศจิกายน 2026 ว่าใช้งานได้บนเครื่องต้นทาง ผลอาจต่างกันตามรุ่นเกม ผังคีย์บอร์ด ค่าปุ่มเกม และอุปกรณ์

## ติดตั้ง

1. ติดตั้ง Karabiner-Elements และชุดกฎหลักตาม [README](../README.md) ตรวจว่า Control+Space ใช้เปลี่ยนภาษา และสำรอง `~/.config/karabiner/karabiner.json` ก่อนแก้ไข
2. คัดลอก `karabiner/warband.json` ไปยัง `~/.config/karabiner/assets/complex_modifications/warband.json` หากมีไฟล์ชื่อนี้อยู่ก่อนให้สำรองและตรวจเนื้อหาก่อน อย่านำไฟล์นี้ไปทับ `karabiner.json`
3. เปิด Karabiner → Complex Modifications → Add predefined rule แล้วเพิ่ม **Warband: external keyboard Ctrl+X and backtick**
4. ลากกฎ Warband ให้อยู่ **เหนือกฎ Backtick และ Ctrl ทั่วไป** การจัดลำดับจำเป็นเพราะ Karabiner ใช้กฎแรกที่ตรงกัน หากมีกฎอื่นที่จับปุ่มเดียวกันอยู่ก่อน ให้ตรวจลำดับด้วย
5. เปิด Enable Cheats ในตัวเลือกเกม แล้วทดสอบ Ctrl+X ในกระเป๋า และปุ่มใต้ Esc ขณะบังคับตัวละคร ตรวจการเปลี่ยนภาษาด้วย

ตัวติดตั้งหลัก `bash install.sh` เพิ่มกฎนี้อัตโนมัติก่อนกฎหลักที่รู้จัก พร้อมสำรองและรักษากฎเดิม ขั้นตอนข้างต้นเป็นทางเลือกติดตั้งด้วยมือ หากมีกฎเดิมอยู่ต่ำกว่ากฎหลัก สคริปต์จะหยุดให้จัดลำดับเอง

## ย้อนกลับ

ปิดหรือลบกฎ Warband ใน Complex Modifications เพื่อคืนพฤติกรรมตามกฎเดิม กฎที่ติดตั้งด้วยสคริปต์ถอนผ่าน `bash uninstall.sh` ได้ ส่วนกฎที่เพิ่มด้วยมือจะไม่ถูกถอนโดยสคริปต์ หากต้องการคืนค่าไฟล์ทั้งหมด ให้สำรองค่าปัจจุบันก่อนแล้วคืนไฟล์สำรองเดิม โดยทราบว่าการคืนทั้งไฟล์จะทับการแก้ไขหลังสำรอง
