# macOS Windows Keyboard

กฎ Karabiner-Elements สำหรับใช้คีย์บอร์ดภายนอกบน macOS: กด Backtick เพื่อสลับไทย–อังกฤษ และใช้ปุ่ม Ctrl แบบ Windows

## ปุ่มที่รองรับ

| ปุ่มบนคีย์บอร์ดภายนอก | ส่งให้ macOS | การทำงาน |
| --- | --- | --- |
| Backtick เดี่ยว | Control + Space | สลับแหล่งป้อนเข้า |
| Ctrl + C | Command + C | คัดลอก |
| Ctrl + V | Command + V | วาง |
| Ctrl + X | Command + X | ตัด |
| Ctrl + Z | Command + Z | ย้อนกลับ |
| Ctrl + A | Command + A | เลือกทั้งหมด |
| Ctrl + S | Command + S | บันทึก |
| Ctrl + F | Command + F | ค้นหา |
| Ctrl + Y | Command + Shift + Z | ทำซ้ำ (Redo) |

- ใช้ได้กับ Ctrl ซ้ายและขวา
- กฎจำกัดเฉพาะคีย์บอร์ดภายนอกด้วย `is_built_in_keyboard: false` ไม่ผูกยี่ห้อหรือรุ่น
- Ctrl+C/V ทำงานใน Apple Terminal และ iTerm2 ด้วยกฎเสริมแยกต่างหาก ส่วน Ctrl+X/Z/A/S/F/Y ยังเว้นสองแอปนี้
- **เมื่อเปิดกฎเสริม Ctrl+C จะคัดลอกข้อความที่เลือก แทนการหยุดคำสั่งที่กำลังรัน** หากต้องการส่ง Ctrl+C เดิม ให้ใช้คีย์บอร์ดในตัว หรือปิดกฎเสริมใน Complex Modifications
- Shift + Backtick ผ่านตามผังภาษาเดิม: ใน ABC จะได้ `~` ส่วนภาษาไทยอาจเป็นอักขระอื่น
- Ctrl + Shift และชุดปุ่มที่ไม่ได้ระบุไว้ไม่ได้เพิ่มการแปลง

## ไฟล์

`karabiner/external-windows-shortcuts.json` เป็นกฎที่นำเข้าได้ ไม่มีโปรไฟล์ทั้งเครื่อง รหัสอุปกรณ์ ไฟล์สำรอง หรือข้อมูลบัญชีส่วนตัว

## ติดตั้งด้วยสคริปต์ (แนะนำ)

ใช้เฉพาะเครื่องมือที่มีใน macOS: Bash, JavaScript for Automation และ Foundation ไม่ต้องติดตั้ง Python/Node เพื่อใช้งานสคริปต์ และ **ไม่ต้องใช้ sudo**

1. ติดตั้ง [Karabiner-Elements จากเว็บไซต์ทางการ](https://karabiner-elements.pqrs.org/) เปิดโปรแกรมและตั้งค่าสิทธิ์ให้เสร็จก่อน สคริปต์นี้ไม่ติดตั้งโปรแกรม ไม่อนุญาตสิทธิ์แทนผู้ใช้ และไม่แก้ค่าปุ่มลัดระบบ
2. เปิดใช้ ABC กับ Thai และตรวจว่า Control + Space เลือกแหล่งป้อนเข้าก่อนหน้า
3. ดาวน์โหลด repo ด้วย **Code → Download ZIP** แล้วแตกไฟล์ หรือใช้ Git หากติดตั้งไว้แล้ว
4. เปิด Terminal ไปยังโฟลเดอร์ repo ที่แตกไว้ และปิดหน้าต่าง Karabiner Settings ระหว่างรันสคริปต์ ไม่ต้องหยุดบริการ Karabiner
5. ดูแผนก่อน แล้วติดตั้ง:

```sh
bash install.sh --dry-run
bash install.sh
```

สคริปต์เพิ่มกฎใน **โปรไฟล์ที่เลือกอยู่** โดยต่อท้ายกฎเดิม ไม่แทนที่รายการกฎหรือค่าอุปกรณ์เดิม กฎที่มีเนื้อหาเหมือนกันจะถูกข้าม แม้ชื่อหรือสถานะเปิด/ปิดต่างกัน จึงติดตั้งซ้ำได้โดยไม่เพิ่มกฎซ้ำ กฎที่ติดตั้งเองมาก่อนจะไม่ถูกนับเป็นของสคริปต์ หากชื่อกฎชนกับกฎเดิมที่มีเนื้อหาต่างกัน สคริปต์จะหยุดให้ตรวจเอง

หากยังไม่มี `karabiner.json` จะสร้างโปรไฟล์เริ่มต้นพร้อมกฎชุดนี้ และบันทึกไว้ว่าเดิมไม่มีไฟล์ กฎเดิมที่ขัดกันอาจมีลำดับความสำคัญเหนือกฎที่เพิ่มใหม่

สคริปต์เพิ่มกฎใหม่ที่ยังไม่มีได้โดยไม่แทนที่กฎเดิม สำหรับรุ่นก่อนที่มีสี่ชุดกฎอยู่แล้ว การรันตัวติดตั้งรุ่นนี้จะข้ามสี่ชุดเดิมและเพิ่มเฉพาะ Ctrl+C/V ใน Terminal ดูขั้นตอนด้านล่าง หากเนื้อหาของกฎเดิมเปลี่ยนเวอร์ชันจริง ๆ สคริปต์จะไม่อัปเกรดทับให้โดยอัตโนมัติ ให้ถอนกฎที่สคริปต์เคยเพิ่มก่อน แล้วติดตั้งใหม่ กฎที่ผู้ใช้แก้ไว้ยังถูกเก็บตามหลักเดิม

หลังติดตั้ง ตรวจ **Devices** ให้คีย์บอร์ดภายนอกที่ต้องการเปิด Modify events และปิดของคีย์บอร์ดในตัว เมาส์/แทร็คแพดไม่ต้องเปิด สคริปต์ไม่เปลี่ยนการเลือกอุปกรณ์หรือ Function Keys ให้เอง

### สำรองและตัวเลือก

ค่าเริ่มต้น:

- ไฟล์ตั้งค่า: `~/.config/karabiner/karabiner.json`
- ไฟล์บันทึกความเป็นเจ้าของกฎ: `karabiner.json.macos-windows-keyboard-state.json` ข้างไฟล์ตั้งค่า **อย่าลบไฟล์นี้หากยังต้องการถอนด้วยสคริปต์**
- สำรอง: `backups/macos-windows-keyboard/<เวลา-รหัสไม่ซ้ำ>/` ภายในโฟลเดอร์ตั้งค่า
- แต่ละสำรองมี `config.before.json` เมื่อเดิมมีไฟล์, `state.before.json` เมื่อมีบันทึกเดิม และ `manifest.json` ที่ระบุสถานะก่อนแก้ไข
- สำรองและตรวจอ่านกลับก่อนเขียนค่าจริงทุกครั้งที่มีการเปลี่ยนแปลง รวมถึงตอนถอน หากเป็น no-op หรือ dry-run จะไม่สร้างสำรองหรือเขียนไฟล์
- เขียนไฟล์ด้วย temporary file แล้ว atomic rename และตรวจว่าไฟล์ไม่เปลี่ยนระหว่างดำเนินการ หากพบการเปลี่ยนแปลงจะหยุดให้ลองใหม่ จึงควรปิดหน้าต่าง Settings ก่อนรัน
- ปฏิเสธไฟล์ตั้งค่า/ไฟล์ state ที่เป็น symlink เพื่อไม่แทนที่ลิงก์โดยไม่ตั้งใจ ใช้ `--config` ชี้ไฟล์จริงหากจัดการ dotfiles ด้วย symlink

เลือกโฟลเดอร์สำรองหรือพาธตั้งค่าเองได้ เช่น:

```sh
bash install.sh --backup-dir "/path/to/your/backup folder"
bash install.sh --config "/path/to/karabiner/karabiner.json"
bash install.sh --profile "ชื่อโปรไฟล์"
bash install.sh --help
```

`--profile` เพิ่มกฎในโปรไฟล์ชื่อที่ระบุ โดยไม่เปลี่ยนว่าโปรไฟล์ใดถูกเลือกอยู่ หากมีชื่อซ้ำหรือไม่พบโปรไฟล์ สคริปต์จะหยุด

## อัปเดตจากรุ่นก่อน

ดาวน์โหลด ZIP รุ่นล่าสุดมาแตกในโฟลเดอร์ใหม่ หรือใช้ `git pull --ff-only` ใน checkout ที่ไม่มีงานแก้ค้างอยู่ จากนั้นปิดหน้าต่าง Karabiner Settings แล้วรัน:

```sh
bash install.sh --dry-run
bash install.sh
```

ถ้ามีสี่ชุดกฎเดิมครบและไม่ได้แก้เนื้อหา ผลที่คาดคือ `skipped_existing_rules: 4` และ `added_rules: 1` กฎเดิมไม่ถูกแทนที่ และมีสำรองก่อนเพิ่มกฎใหม่ หากเคยใช้ `--config`, `--profile` หรือโฟลเดอร์สำรองเฉพาะ ให้ใช้ตัวเลือกเดิมตามต้องการ

กฎใหม่ชื่อ **External keyboards: Windows Ctrl C V in Terminal and iTerm2** เปิดเป็นค่าเริ่มต้นเมื่อติดตั้งด้วยสคริปต์ ปิดกฎนี้ใน Complex Modifications เพื่อคืน Ctrl+C สำหรับหยุดคำสั่งใน Terminal โดยคง Ctrl+C/V ในแอปอื่นไว้ การรันติดตั้งซ้ำจะไม่เปิดกฎที่คุณปิดไว้ให้เอง

หากกฎเดิมนำเข้าเอง การถอนด้วยสคริปต์จะถอนเฉพาะกฎใหม่ที่สคริปต์เพิ่ม ส่วนกฎเดิมที่นำเข้าเองยังคงอยู่

## ถอนด้วยสคริปต์

รันจากโฟลเดอร์ repo เดิม:

```sh
bash uninstall.sh --dry-run
bash uninstall.sh
```

ถ้าตอนติดตั้งใช้พาธตั้งค่าเอง ต้องส่ง `--config` พาธเดียวกันตอนถอนด้วย ส่วน `--backup-dir` เลือกได้เช่นเดียวกับตอนติดตั้ง

การถอนจะค้นทุกโปรไฟล์ และลบเฉพาะกฎที่มีเครื่องหมายติดตั้งตรงกับบันทึกของสคริปต์ กฎเดิมและกฎที่เพิ่มภายหลังจะคงอยู่ ไม่คืนไฟล์สำรองทั้งก้อนทับค่าปัจจุบัน ไม่ถอน Karabiner ไม่ลบไฟล์สำรอง และไม่ลบไฟล์ตั้งค่าแม้เป็นไฟล์ที่สร้างใหม่

ถ้าผู้ใช้แก้เนื้อหากฎที่สคริปต์เพิ่มไว้ การถอนจะเก็บกฎนั้นและบันทึกไว้ แสดง `status: partial` พร้อมรายการ `preserved_edited_rules` ให้ตรวจและปิด/ลบเองใน Karabiner การเปิด/ปิดกฎเพียงอย่างเดียวไม่ถือเป็นการแก้เนื้อหา หากแก้ชื่อกฎจนเครื่องหมายติดตั้งหายไป กฎนั้นจะไม่ถูกลบอัตโนมัติ

ถ้าบันทึก state สูญหาย สคริปต์จะไม่เดาความเป็นเจ้าของกฎ ให้ปิดกฎด้วยตนเองใน Complex Modifications หากสคริปต์ถูกหยุดกะทันหันแล้วมีไฟล์/โฟลเดอร์ `.macos-windows-keyboard.lock` ค้าง ตรวจว่าไม่มีสคริปต์กำลังทำงานก่อนนำ lock ที่ระบุในข้อความผิดพลาดออก

## ติดตั้งด้วยตนเอง (ทางเลือก)

1. ติดตั้ง [Karabiner-Elements จากเว็บไซต์ทางการ](https://karabiner-elements.pqrs.org/) และอนุญาตบริการ/สิทธิ์ที่โปรแกรมระบุ ไม่ต้องปิด SIP หรือแก้ไฟล์ระบบ
2. เปิดใช้ภาษา **ABC** และ **Thai** ใน macOS ตรวจว่า **Control + Space** เป็นปุ่มเลือกแหล่งป้อนเข้าก่อนหน้า กฎนี้เพียงส่งปุ่มลัดดังกล่าว ไม่เปลี่ยนค่าปุ่มลัดระบบให้
3. สำรอง `~/.config/karabiner/karabiner.json` ไปยังที่ปลอดภัยก่อนแก้ไข และสำรองไฟล์กฎชื่อเดียวกันหากมีอยู่แล้ว
4. ดาวน์โหลดหรือ clone repo นี้ แล้วคัดลอก `karabiner/external-windows-shortcuts.json` ไปยัง `~/.config/karabiner/assets/complex_modifications/` สร้างโฟลเดอร์หากยังไม่มี **อย่านำไฟล์กฎนี้ไปทับ karabiner.json**
5. เปิด Karabiner → **Devices** ปิด **Modify events** ของคีย์บอร์ดในตัว และเปิดเฉพาะคีย์บอร์ดภายนอกที่ต้องการ เมาส์/แทร็คแพดไม่จำเป็นต้องเปิด
6. ไปที่ **Complex Modifications → Add predefined rule** เลือกกฎจากชุด **External Windows keyboard shortcuts** แล้วเพิ่มกฎที่ต้องการ หากมีรุ่นเก่าของกฎเดียวกัน ให้ปิดกฎเก่าก่อนเพื่อไม่ให้ซ้ำ

คีย์บอร์ดภายนอกมาตรฐานที่ Karabiner รับเหตุการณ์อยู่แล้วจะตรงกับกฎโดยอัตโนมัติ ทั้ง USB และ Bluetooth รุ่นที่รายงานตัวเป็นทั้งคีย์บอร์ดและอุปกรณ์ชี้ตำแหน่งอาจต้องเปิด Modify events ให้ครั้งแรก

## ข้อจำกัด

- ปุ่มใต้ Esc ต้องส่ง `grave_accent_and_tilde` รุ่น ISO/JIS หรือเฟิร์มแวร์บางแบบอาจส่งรหัสต่างกัน ตรวจได้ด้วย EventViewer
- Backtick เดี่ยวบนคีย์บอร์ดภายนอกจะใช้พิมพ์เครื่องหมายเดิมไม่ได้เมื่อเปิดกฎเปลี่ยนภาษา กดค้างจะไม่สลับภาษาซ้ำ
- ถ้ามีแหล่งป้อนเข้ามากกว่าสองภาษา Control + Space อาจสลับไปภาษาอื่นตามประวัติ ไม่รับประกันว่าจะสลับเฉพาะไทย–อังกฤษ
- เงื่อนไขแอป Terminal ใช้ bundle ID ของ Apple Terminal และ iTerm2 เท่านั้น ไม่ครอบคลุม Terminal ที่ฝังในแอป เช่น VS Code หรือแอป Terminal อื่น ซึ่งจะได้รับกฎ Ctrl ชุดทั่วไปตามแอปที่เปิดอยู่
- กฎ Ctrl+C/V ใน Terminal ไม่ตรวจว่ามีข้อความถูกเลือกหรือไม่ หากไม่ได้เลือกข้อความ Ctrl+C ก็ยังถูกส่งเป็น Command+C และจะไม่ส่งสัญญาณหยุดคำสั่ง
- Redo ใช้ Command + Shift + Z แอปที่ใช้ปุ่มลัดต่างออกไปต้องเพิ่มกฎเฉพาะแอป
- ปุ่ม Ctrl ที่มีหน้าที่เฉพาะในแอปอื่นอาจถูกแทนด้วยปุ่ม Command ตามตาราง
- Karabiner ต้องทำงานอยู่ การเลือกชนิดคีย์บอร์ดเสมือนและการตั้งค่า Function Keys ของ Karabiner อาจมีผลกับปุ่มอื่น ควรตรวจตามคีย์บอร์ดที่ใช้

## ตรวจสอบ

ชุดทดสอบ integration ใช้ไฟล์ตั้งค่าจำลองเท่านั้น ครอบคลุมการสำรอง การติดตั้งซ้ำ การถอน กฎเดิม หลายโปรไฟล์ JSON เสีย symlink และกฎที่ผู้ใช้แก้ภายหลัง ผู้พัฒนารันบน macOS ได้ด้วย `python3 -m unittest discover -s tests -v` (Python ใช้สำหรับทดสอบเท่านั้น ไม่ใช่ dependency ของตัวติดตั้ง)

ไฟล์กฎผ่านตัวตรวจรูปแบบของ Karabiner-Elements 16.3.0 และตรวจว่ากฎโหลดเปิดใช้งานได้ การตรวจดังกล่าวไม่ได้รับรองผลกับทุกคีย์บอร์ด ทุกแอป หรือหลังรีสตาร์ต

คำสั่งตรวจรูปแบบบนเครื่องที่ติดตั้ง Karabiner:

```sh
"/Library/Application Support/org.pqrs/Karabiner-Elements/bin/karabiner_cli" \
  --lint-complex-modifications karabiner/external-windows-shortcuts.json
```

ควรลองกับเอกสารว่าง: สลับภาษาไปมา, Shift + Backtick ใน ABC, Ctrl+C/V/X/Z/A/S/F/Y และตรวจปุ่มคีย์บอร์ดในตัว รวมถึง Ctrl+C/V ใน Terminal โดย Ctrl+C ต้องคัดลอกข้อความที่เลือก และเมื่อปิดกฎเสริมต้องกลับมาหยุดคำสั่งได้

## ย้อนกลับด้วยตนเอง

- หยุดกฎใดกฎหนึ่ง: Karabiner → **Complex Modifications** → ปิดสวิตช์กฎนั้น กฎอื่นยังคงทำงาน
- คืนโปรไฟล์ทั้งหมด: สำรองค่าปัจจุบัน แล้วนำ `karabiner.json` ที่สำรองก่อนติดตั้งกลับ ขณะไม่ได้แก้ค่าผ่านหน้าต่าง Settings พร้อมกัน
- ถอนโปรแกรมทั้งหมด: ใช้เมนู **Uninstall** ของ Karabiner เพื่อถอดบริการและไดรเวอร์อย่างถูกต้อง แล้วตรวจสิทธิ์ Accessibility/Input Monitoring และ Login Items & Extensions ที่เพิ่มไว้
